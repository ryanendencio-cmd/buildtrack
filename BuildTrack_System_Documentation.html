1. BACKEND ARCHITECTURE & TECH STACK

Component Technology Role & Implementation Details
Server Framework Express.js v5.2.1 (Node.js) Monolithic REST API server handling request validation, routing, JSON payload parsing, and CORS policies.
Primary Database Google Firebase Firestore NoSQL Cloud Document Database managed through firebase-admin v14.5.0 service account credentials.
Security & Encryption bcrypt v6.0.0 One-way salted password hashing for both Admin web accounts and Worker mobile profiles.
Session Tokens jsonwebtoken (JWT) v9.0.3 Stateless token authentication for secure admin sessions and password reset authorization.
Notification Engine Nodemailer v10.0.13 SMTP email transport service used for automated admin password recovery verification codes.
Large Payload Support express.json (Limit: 50MB) Supports high-resolution receipt image uploads, base64 avatars, and OCR transaction attachments.

3. END-TO-END WORKFLOW ARCHITECTURE

A. User Onboarding & Access Control
• Admin Web: Direct secure login via /api/admin/login with session tokens. Includes email-based password recovery via Nodemailer.
• Mobile Workers: Self-registration on Flutter app enters a Pending approval state. Admin approves worker profiles on Web Dashboard before login access is granted.
B. Project Creation & Dynamic Budget Allocation
• Admin registers projects on Web Portal with base capital allocation.
• Live project expense tracking deducts from budget in real time.
• Additional project capital injections are recorded via /api/projects/:id/budget-additions for transparent financial auditing.
C. Expense Tracking & OCR Receipt Integration
• Site engineers and staff log material and logistical costs.
• Receipts can be captured directly or scanned via client-side OCR for automated field filling.
• Aggregated financials are served via monthly and category summary endpoints for analytics charts.
D. Attendance Monitoring & On-Site QR Verification
• Personnel designated with Attendance Monitoring position use the Mobile App to scan worker QR identification.
• Time-in, Time-out, and late calculations sync instantly to Firestore.
• Admin monitors real-time headcounts, present lists, and manpower costs on the Web Portal.
E. Equipment Custody & Tool Checkout Pipeline
• Web Portal (Admin): Strictly handles tool inventory creation, editing, maintenance logs, and monitoring unreturned tools.
• Mobile App (Field Custodian): Exclusively manages tool Check-Out on-site.
• Returns update tool condition (Good / Needs Repair / Broken) and automatically archive to borrow_history.
F. Worker Cash Advance (Bale) Lifecycle
• Workers submit cash advance requests via Flutter Mobile App with specified amounts and reasons.
• Requests surface on Admin Web Portal under Pending Advances.
• Admin approval/rejection updates worker balance ledger and logs the transaction.
